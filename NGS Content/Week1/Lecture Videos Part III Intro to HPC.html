You will hear reference to the "Prince" cluster, but this has been superseded by the "Greene" cluster as of 2024.

Another major development since this recording was produced is the release of Open OnDemand (OOD). OOD provides a browser-based interface to the HPC with many advantages. It provides operating system-independent access option that MacOS, Linux and PC users can use without the need to ssh into the cluster on a Unix-based terminal. This means PC users don't need to use WSL or Unix emulator to gain access. There are many other advantages which we will see throughout the course. We will do a short demo in the Week 1 session.

Also new as of 2024, your HPC account now has a /vast directory with 2 Tb of storage. /vast is like /scratch in that it is meant for I/O intensive jobs, but /vast has even more efficient I/O than /scratch that improves performance of I/O intensive jobs. Like /scratch, /vast also is flushed every 60 days.

You can read more about  NYU /vast and other data management considerations here:

In video 5, we discuss the challenges of scale and how array jobs can simplify the execution of many simultaneous jobs that execute the same workflow, but in an ordered way, for example on 10-1000 samples. However, a major development since 2019 is the widespread transition to using Workflow Management Systems like Snakemake and Nextflow. Array jobs are an excellent solution for medium scale jobs, particularly for relatively simple (linear) workflows and when you are only running a workflow once. However, for more complicated workflows (non-linear workflow or those with job dependencies) those that process very large scale data, and those that you need to run many times independently, then it makes sense to invest time in developing a Nextflow pipeline for your job. Of course, projects like nf-core (https://nf-co.re/), already have many pipelines for most common NGS tasks already pre-built. We will explore Nextflow and nf-core in detail later in the course.
